7. 在“个人 → 交互与触感”选择关闭、轻柔或标准，并点“试一下触感”。默认轻柔，按钮、字号与行距刻度均有反馈，遵循系统触感开关；标准保留较清晰的开关和切章反馈。

## 0.5.11 首次阅读与连续切章优化

## 全屏与弹窗

页面背景与正文滚动区域延伸至屏幕上下边缘。点击空白收起 Dock 时，原生 Android 同时隐藏顶部状态栏与底部导航栏；再次点击或返回首页恢复。系统栏支持边缘滑动临时唤出。系统栏显隐使用稳定安全间距，避免正文因间距变化跳动。

底部在所有阅读状态下均不使用渐变、模糊或遮罩。顶部仅保留一小段轻微的渐变模糊，读取系统提供的顶部摄像头或刘海区域高度，在其底缘附近（多 4dp 过渡）结束；没有顶部开孔时使用短过渡。此效果需在具体手机上核对。

按钮和 Dock 仍按安全区域避让；键盘弹出时调整可用区域。普通弹窗后方仅压暗，不模糊；阅读中的半屏主题与排版面板不压暗正文，便于实时预览。首页右上角使用指南集中说明操作，阅读时不显示底部提示。

## 统一交互与动效

- 按钮和选项：按下轻微收缩，松手弹性回到原位，滚动或取消手势时释放按压状态。
- 主导航胶囊：拖动时跟手并按速度轻微拉伸，释放后按弹簧曲线回到目标位置。保留静态玻璃质感，不恢复周期扫光、呼吸光晕或白色短横线。
- 带顶部小横条的面板：统一从屏幕底部向上滑入（240ms），向下滑出关闭（170ms），保持卡片尺寸。下拉关闭与取消回弹也遵循同一方向。
- 释义、插图和摘句卡片：保留关联来源的展开与返回，出现缩短为 280ms、收起为 150ms。连续打开新面板时，旧关闭动画不会删除新面板。
- 设置层级：从主题进入自定义配色等子设置后，关闭或系统返回先回到原来的父面板，保留滚动位置。可从面板内容区或顶部手柄下拉关闭；内容先滚动到顶部，同一手势的剩余距离再带动卡片。慢拉跟手、快速下甩或拉远后松手关闭，轻拉或取消后回弹。拖动经过按钮不会误触。
- 页面与图书：按导航方向离开与进入，主页面左右切换总时长约 260ms，切换离开期仍可点击原内容以取消导航；正文慢滑跟手显示相邻章，手势松手后按释放速度约 180–420ms 减速归位或切换（极短余量 120ms），首尾不循环，长按选句、纵向滚动与系统边缘手势保留；从书架、搜索或笔记进入阅读后，阅读页返回按钮回到来源页并恢复滚动位置。底部“回到书架”仍明确回到书架。
- 段落翻译：在原有段落内出现和收起，保留正文节点和阅读锚点。摘句按钮从所选文字附近展开，取消时逆向收回。
- 减少动态：在“个人 → 阅读偏好 → 减少动态效果”开启后，跳过弹簧与展开位移；同时尊重系统减少动态偏好。

动效采用统一的圆角、反馈与缓动参数。没有加入空闲循环动画，不修改系统文件选择器、键盘等由 Android 控制的界面。

## 自定义主题色

进入“个人 → 主题色彩”，或“阅读 Dock → 主题 → 自定义主题色”。支持六款主色预设、自选主色和页面底色、十六进制色号输入、实时预览、自动保存及恢复默认。文字色随底色调整；主题色同时影响 Dock、选中胶囊和按钮。选择纸页预设会恢复预设底色，保留自选主色。

## 词典与发音

进入“个人 → 词典与发音”，或阅读“语言 → 词语释义”，统一设置默认词典、横滑顺序、免费在线来源、口音与发音来源。支持导入词典、7,974 个 ECDICT 离线英汉词条、Free Dictionary 英英释义、MyMemory 词语翻译和可选 Google 试用通道。移除旧牛津官网模式与常驻语音安装按钮；已有授权词典仍可自行导入。

单词卡上方整个固定区域可上下拖动，跟手展开、收起或下拉关闭，按钮保持轻点操作；释义区保留原生上下滚动、横滑切词典。保留单喇叭及音标旁小型英美选择，不增加双喇叭。

默认优先本地词典/资源录音，缺少或失败时静默使用系统发音，成功播放不提示错误。可主动选择免费在线录音，查询有有限等待，失败仍回退系统。只有所有发音路径均失败时显示一次提示并提供语音设置入口。系统缺少所选口音时可使用通用英语，并明确标注。已识别的英美音标及弱读/强读分别保留，不按拼写推造音标。

免费服务有额度与可用性限制：MyMemory 匿名每天 5,000 字符；Free Dictionary 并非每词、每种口音都有录音；Google 使用现有免 Key 试用通道，并非无限量的正式 Cloud Translation API。在线音频仅接受明确允许的 HTTPS 服务，默认发音不请求网络。

## 边界与已知限制

- 这是 0.5.18 更新版，检查包括 JS 逻辑/受控事件、原生配置/模拟与 Chromium 真实触摸输入回归。原生检查使用模拟 View/服务；没有真实手机触感、帧时间、GPU、内存峰值或耗电测量。
- 本版增加浏览器渲染和真实触摸输入验证，覆盖纵向卡片、指南惯性和全屏图片。Chromium 触摸模拟不能替代 Android WebView 真机验收；系统栏、屏幕边缘及实际滚动手感仍需在手机上确认。
- 阅读核心使用本地 WebView 页面，系统文件选择、下载、语音、网络请求与密钥加密由 Java 处理。玻璃控件使用半透明、轻量纹理、高光和阴影；移动的阅读 Dock 不再实时模糊背后正文，避免弹出时不断采样与重算。阅读页只有顶部摄像头附近的短区域使用轻微渐变背景模糊，底部始终没有渐变模糊，控件和弹窗不使用实时背景模糊，打开弹窗只压暗背景。未使用苹果原生 Liquid Glass。
- 默认 Google 公共翻译入口为尽力支持的无 Key 在线方式，其稳定性和访问条件不受本 App 控制。本环境的 Google 与 MyMemory 请求曾返回 HTTP 429，未验证真实在线翻译成功。可在“个人 → 翻译服务”配置 OpenAI 兼容 API；实际请求由所选服务商处理和计费。
- MyMemory 模式采用 每请求 450 UTF-8 字节预算，长段按边界分块后合并，不截断原文。图书缺少有效语言标记时提示使用自动识别原文的 Google 或自定义 AI。

- 默认轻柔模式补齐设置、筛选、笔记操作、搜索入口、主题预览和普通操作按钮反馈；语义操作仍由自身成功或状态改变节点处理，避免一次触摸震两次。点击当前导航、当前主题等也给轻反馈。

- 字号和行距在轻柔模式就有细微刻度感，不再要求切换标准。只在数值变化时反馈，连续刻度仍限频；新触摸允许立即得到第一下刻度反馈，所有数值实时生效。

## 0.4.8 触感与性能优化

- 新增“个人 → 交互与触感”：关闭、轻柔、标准及预览；旧数据默认轻柔。优先使用系统语义反馈，尊重系统开关，不新增震动权限、不强制绕过系统设置。
- 导航、Dock 拖动选择、翻译/设置开关、实际切章和成功收藏提供反馈。正文纵向滚动、点空白、普通查词和卡片回弹保持安静；长按选字沿用系统反馈。标准模式增加普通按钮和滑块刻度。收藏失败不播放成功反馈，重复点击不会双震。
- 触感独立进入原生 UI 队列，页面操作不等待震动完成。仅密集刻度反馈限频并带选项边界滞回，按钮没有新增等待时间。系统关闭触感、设备不支持或 App 在后台时可能没有震感；此时操作照常完成。
- 保持所有动效时长、弹性参数、手势阈值、样式、完整正文和原有操作。缓存相同弹簧结果，并用上一版曲线样本验证一致；缓存返回独立副本以避免污染。
- 文字分词缓存最多 256 条、共 400,000 字符（原文与生成标记合计），过大的段落仍完整处理但不驻留缓存。收藏、译文等动态状态仍实时应用。
- 阅读进入后延迟安排空闲分片：准备相邻章预览所需文字和最多两张本地插图；每片最多两项。触碰、导航、后台时取消可选准备；离书和后台释放图片引用。不会为预览发起翻译或网络请求，不缩减插图清晰度。
- 字号与行距实时生效，连续调整合并保存，松手/change 与后台时立即提交；已有配色的连续保存也会在结束时清理重复任务。仅明暗状态变化才通知原生系统栏，未变的自定义配色复用结果。
- 滚动进度条每帧提交一次最新位置；离开页面取消待绘制任务。保存进度仍正常进行，定位可见段落改用有序查找，减少长章节中的布局读取。
- 模拟计数验证：15 次字号 input 合并为 1 次结束保存；20 次滚动事件只排 1 次进度绘制；1,024 段中定位第 850 段不超过 11 次边界读取。以上是受控操作计数，不能换算为真实帧率或功耗提升。
- 原应用 id、数据版本、签名和书籍/收藏结构保持兼容，可直接覆盖安装 0.4.7 及更早版本，不需要卸载。

## 0.4.7 首次触摸与插图滑动修复

- 按钮触摸/触控笔在有效抬起时执行一次操作，不依赖后续兼容 click；后续同次 click 只去重，不阻止下一次触摸。鼠标、键盘、读屏与程序点击保留原路由。
- 按压缩放仅作用于按钮内部图标和文字，外部命中区域保持固定；原始与当前位置均参与抬起校验，避免入口移动时漏点。拖动、取消、长按菜单、多指、后台、失效或禁用控件不执行。
- 插图及其按钮留白加入阅读横滑。左右慢拖可跟手切章；短拖回弹；纵向滚动保留，轻点仍可放大。禁用图片原生拖拽，横滑不会额外打开插图。
- 面板、正文和 Dock 的拖动统一取消本次点击候选；统一同步隐藏/显示的 inert 属性与 CSS 命中状态，避免旧控件继续接收输入，并保证复习按钮、阅读工具栏恢复后可以首次点击。
- 新增 41 项受控回归，使用非零模拟几何范围、触摸捕获交接、首次抬起不补 click、兼容 click 去重及插图起手。0.4.6 在两条对应的模拟重现路径中均失败；本版通过。该结果不代表手机输入验收。
- 原应用 id、数据结构和签名保持一致；可覆盖安装 0.4.6 及更早版本。请保留原安装数据，不需要卸载。
